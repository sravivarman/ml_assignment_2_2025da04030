## a. Problem Statement
Breast cancer diagnosis relies on correctly classifying tumors as malignant or benign based on measurements taken from digitized images of a fine needle aspirate (FNA) of a breast mass. The goal of this project is to build and compare multiple machine learning classification models that predict whether a tumor is malignant or benign, and to expose these models through an interactive Streamlit web application so predictions and evaluation metrics can be explored on demand.

## b. Dataset Description
Dataset Name: Breast Cancer Wisconsin (Diagnostic) Data Set
Sourse: https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data
No. of Instances: 569
No. of Features:
    30 predictor (numerical) features
    1 target variable (Diagnosis: 0 = Malignant, 1 = Benign)
    1 ID column
